# Provenance and authorship

The research question and project direction come from Aahana Gupta's dementia-assessment work and predate this public repository.

This GitHub repository was consolidated in **October 2026** as a reproducibility layer. It uses synthetic data and later public-facing analysis/demo code so that methods can be inspected without exposing participant data.

AI-assisted development tools were used in parts of that later public layer. The repository does not represent those additions as recovered clinical production code or as a substitute for the underlying study records.

No patient-identifiable data is included here.
